# Zen Radio

*Listen. Breathe. Be.*

A minimalist internet radio player — designed to quiet the noise and let the music flow.

**[zen-radio.app](https://zen-radio.app)**

---

### What is this?

Zen Radio is a fullscreen Progressive Web App that connects you to thousands of radio stations worldwide through the [Radio Browser](https://www.radio-browser.info/) community directory. No accounts. No ads. No distractions. Just sound.

Install it on your home screen. Press play. That's it.

---

### Features

- Search thousands of stations by name, genre, or mood
- Favorite stations for instant access
- Recent history — pick up where you left off
- Hardware media key support (keyboard, headphones, lock screen)
- Works offline once installed (cached app shell)
- Respects your language (EN, ES, FR, DE, JA, RU, ZH)
- Dark, glassmorphic UI that stays out of the way

---

### Run locally

```
npm install
npm run dev
```

Open [localhost:5173](http://localhost:5173).

### Build

```
npm run build
```

Static output lands in `build/client/`.

---

### Stack

Remix (SPA mode) / TypeScript / Tailwind CSS v4 / react-i18next / Radio Browser API
